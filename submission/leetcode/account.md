# LeetCode Account

- **Problem:** Reverse String
- **Language:** C#
- **Difficulty:** Easy
- **Status:** Accepted

## Solution Approach

The solution uses the two-pointer technique.

One pointer starts from the beginning of the array, while the other starts from the end. The characters at both positions are swapped, then the pointers move toward the center.

The input `char[]` is modified in place without using any built-in method to reverse the array.

## Complexity

- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
